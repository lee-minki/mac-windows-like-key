## 01 Icon Candidate A

Use case: logo-brand

Asset type: 1024x1024 macOS app icon concept, candidate A for WinMacKey.

Primary request: Create a polished macOS-style utility app icon for a Korean/English input switching app. The icon should communicate: the right-side Command key becomes the Han/English toggle key.

Subject: A single large rounded-square keyboard keycap, viewed slightly from above. The keycap is positioned as the right modifier key: its visual weight and a tiny right-edge alignment cue imply "right side". On the key surface, use a clean Command symbol and a minimal language-toggle motif: one abstract Hangul block shape and one Latin A shape connected by a small swap arrow. Keep symbols large and simple.

Style: premium macOS app icon, tactile off-white keycap, graphite base, subtle green/cyan accent light, crisp edges, highly readable at small icon sizes.

Composition: centered object, generous safe margins, no busy background.

Avoid: Apple logo, official Microsoft Windows logo, exact Windows logo, brand names, words, WMK letters, paragraphs, watermark, complex keyboard scene, small UI text, dark circuit-board clutter.
