## D. 🔴 프로필 위자드 Fn 감지 — 회귀 진단 (이번 버그의 핵심)

> 설정 → Profiles → "새 프로필 만들기" → 표기 선택 → **Step 2 "현재 입력 감지"** 진입.
> 목표: "Fn 만 안 잡히는지" vs "modifier 전부 안 잡히는지" 를 분리해 원인을 확정한다.
> 본질: 표기(Mac/Win)는 표시용이고, 기능 축은 **좌측 3키 vs 4키 + Space** 다(FEATURE_SPEC §2.1). 4키의 네 번째 키가 Fn 이므로, 이 섹션은 곧 **"4키 구성을 끝까지 등록할 수 있는가"** 테스트다.

- [ ] **D1** Step 2 에서 **Ctrl** 한 번 누름
  - 기대: 슬롯이 "대기"→Ctrl 로 채워짐 — *실제:* ______
- [ ] **D2** **Cmd** 누름 → 채워짐 / **Opt** 누름 → 채워짐
  - 기대: 둘 다 채워짐 — *실제:* ______
- [ ] **D3** **Fn(🌐)** 누름 — *v1.4.0 IOHID 감지 핵심 검증*
  - 기대: 슬롯이 Fn 으로 채워짐 (IOHID 0x00FF 경로). 채워지면 신규 맥북 Fn 감지 수정 확인 — *실제:* ______
- [ ] **D4** (D3 가 안 채워질 때) **"+ Fn 🌐" 버튼** 클릭 — *보장 폴백*
  - 기대: Fn 슬롯이 좌측 끝에 추가됨 (감지 없이도). 이후 Space → 4키 확정 가능 — *실제:* ______
- [ ] **D5** D3·D4 로 4키 구성 후 Space → 다음 단계 → 저장 → 실제 타이핑에서 Fn 리맵 동작 확인
  - 기대: 저장 프로필의 Fn 매핑이 런타임(hidutil)에서 동작 — *실제:* ______
- [ ] **D6** (참고, D3 실패 시 원인 분리) 시스템 설정 → 키보드 → **"🌐 키를 다음 용도로 사용" → "아무 작업 안 함"** 후 Fn 재시도
  - 기대: 이걸로 D3 가 되면 원인 = Globe 키 소비(CGEventTap). IOHID 경로도 검토 필요 — *실제:* ______
