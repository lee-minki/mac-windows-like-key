## D. 프로필 위자드 — 표 기반 매핑 검증 (v1.6.0+)

> 설정 → Profiles → **"새 프로필 만들기"** → 시작·의도 화면 진입.
> v1.5.x 이하의 옛 Fn 감지(Step 2 캡처) 진단은 **v1.6.0 에서 위자드 캡처가 완전 제거되어 의미 없음.** 표 기반 위자드는 키를 누를 필요 없이 표만 채우면 된다 — Mac/Win 듀얼모드 키보드 포함 모든 키보드에서 동일 동작.

- [ ] **D1** 시작 화면에서 프로필 이름 입력 후 **"한/영 전환만"** 클릭
  - 기대: 식별 프로필 즉시 생성 + 활성화, 위자드 닫힘. 메뉴바 엔진 토글 활성화 — *실제:* ______
- [ ] **D2** 새 프로필 만들기 → **"키 배치도 바꾸기"** → 표 화면
  - 기대: 4행(Fn·Ctrl·Opt·Cmd) × 2열(Mac·VDI) picker 표시. 모든 행 default = "안 바꿈" — *실제:* ______
- [ ] **D3** 표 상단 키캡 표기 토글 → **Windows (Win/Alt)**
  - 기대: `Opt` → `Alt`, `Cmd` → `Win` 으로 라벨만 바뀜 (행 순서·키코드 동일) — *실제:* ______
- [ ] **D4** **"Windows 감각"** 버튼 클릭
  - 기대: Mac 열의 Ctrl 행 = `Cmd`, Cmd 행 = `Ctrl` 로 채워짐 (스왑). VDI 열 변동 없음. 미리보기에 `Ctrl→Cmd  Cmd→Ctrl` 표시 — *실제:* ______
- [ ] **D5** "다음 →" → 확인 화면 → **"저장하고 적용"**
  - 기대: 활성 프로필로 즉시 적용, 위자드 닫힘. 실제 타이핑에서 ⌘C/⌘V 가 Ctrl 키로 동작 — *실제:* ______
- [ ] **D6** 저장된 프로필을 다시 편집 → 매핑 표 → 변경 없이 **"변경 저장"**
  - 기대: round-trip 무손실. 옵셔널 3필드(auxiliaryFnKey/bundleId/deviceIdentifier) 보존 — *실제:* ______
- [ ] **D7** active 프로필 휴지통 삭제
  - 기대: 즉시 제거 + `activeMappingProfileId="standardMac"` 리셋 + custom HID 매핑 clear — *실제:* ______
