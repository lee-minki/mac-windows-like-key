👋 WinMac Key란?

Windows에서 Mac으로 넘어온 분들을 위한 키보드 매핑 앱입니다.

Windows에서 오래 사용하던 키보드 습관 — 우측 Command로 한/영 전환, Ctrl+C/V 복사/붙여넣기 — 이 Mac에서 그대로 동작하지 않아 불편하셨죠?


WinMac Key는 Mac 키보드의 하단 modifier 키 배치를 Windows와 유사하게 자동 변환해주고, Right Command 키 하나로 한/영 전환을 가능하게 합니다.


✅ 별도 드라이버 불필요 · 관리자 비밀번호 불필요 · 재부팅하면 원상복구

📦 설치하기

3분이면 끝나는 간단한 설치 과정입니다.

1

DMG 파일 다운로드

GitHub Releases 페이지에서 최신 .dmg 파일을 다운로드합니다.

2

Applications 폴더로 이동

DMG를 열면 WinMac Key 아이콘과 Applications 폴더 바로가기가 보입니다. 아이콘을 Applications로 드래그합니다.

⚠️ Downloads 폴더에서 직접 실행하면 Spotlight에 중복 표시될 수 있습니다. 반드시 Applications로 이동하세요.
3

최초 실행 (서명·공증 완료)

v1.3.8 이후 빌드는 Apple Developer ID 서명 + 공증(Notarization)을 거쳤습니다. 별도의 우회 절차 없이 더블클릭으로 바로 실행됩니다.

ℹ️ 이전 버전(~v1.3.7)은 서명이 없어 "확인되지 않은 개발자" 경고가 떴고 우클릭→열기 또는 xattr 우회가 필요했습니다. v1.3.8부터 Apple 공증을 통과해 Gatekeeper 경고 없이 설치됩니다. 예전 버전을 이미 허용해 쓰던 분도 그대로 업데이트하면 됩니다.
4

앱 실행

Launchpad 또는 Spotlight(⌘+Space)에서 "WinMac Key"를 검색하여 실행합니다. 메뉴바(화면 우측 상단)에 WinMac Key 아이콘이 나타나면 성공입니다. (엔진이 꺼져 있을 땐 흐릿한 외곽선으로 표시됩니다.)

ℹ️ v1.8.3부터 Applications 설치본이 있으면 다른 폴더의 복사본은 입력 엔진을 시작하지 않습니다. 새 릴리스 확인은 기본으로 켜지며 설정의 Startup 카드에서 끌 수 있습니다. 설치는 업데이트 창에서 사용자가 확인한 뒤 진행됩니다.

⚙️ 초기 설정 (필수)

앱이 정상 동작하려면 아래 4단계를 반드시 완료해야 합니다.

1

🔐 손쉬운 사용 권한 허용

WinMac Key는 키보드 입력을 가로채기 위해 macOS의 "손쉬운 사용(Accessibility)" 권한이 필요합니다.

  1. 앱을 처음 실행하면 권한 요청 팝업이 표시됩니다.
  2. "시스템 설정 열기"를 클릭합니다.
  3. 시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용으로 이동합니다.
  4. 목록에서 "WinMac Key"를 찾아 토글을 켭니다.
  5. Mac 비밀번호를 입력하여 확인합니다.
⚠️ 권한 허용 후 앱을 한 번 재시작해야 적용될 수 있습니다.
2

🔤 CapsLock 한/영 전환 끄기

macOS 기본 CapsLock 한영전환이 WinMac Key와 충돌하지 않도록 비활성화합니다.

  1. 시스템 설정 → 키보드로 이동합니다.
  2. "입력 소스" 섹션에서 "모든 입력 소스"를 클릭합니다.
  3. "Caps Lock 키로 ABC 입력 소스 전환" 체크를 해제합니다.
3

⌨️ 입력 소스 단축키 확인 (가장 중요!)

WinMac Key는 내부적으로 "이전 입력 소스 선택" 단축키(Control+Space)를 합성합니다. 이 항목이 반드시 올바르게 설정되어 있어야 합니다.

  1. 시스템 설정 → 키보드 → 키보드 단축키...를 클릭합니다.
  2. 좌측 목록에서 "입력 소스"를 선택합니다.
  3. "이전 입력 소스 선택"의 체크박스가 켜져 있는지 확인합니다.
  4. 단축키가 "^ Space" (Control + Space)인지 확인합니다.
  5. 다른 키로 되어 있다면 더블클릭 후 Control + Space로 변경합니다.
  6. "완료"를 클릭합니다.
⚠️ 이 항목이 꺼져 있거나 다른 키로 바뀌어 있으면 WinMac Key의 한/영 전환이 동작하지 않습니다!
4

🚀 엔진 활성화

설정이 끝나면 WinMac Key 엔진을 켭니다.

  1. 메뉴바(화면 우측 상단)에서 WinMac Key 아이콘을 클릭합니다.
  2. "엔진 상태" 토글을 켭니다.
  3. 아이콘이 또렷하게 채워진(불투명) 모양으로 바뀌면 활성화 완료! (꺼짐 = 흐릿한 외곽선)
  4. Right Command 키를 눌러 한/영 전환이 되는지 테스트합니다.
ℹ️ v1.3.8부터 엔진 ON/OFF를 아이콘 채움·불투명도로 구분합니다. 메뉴바가 아이콘 색을 단색으로 강제해도 채워진 정도와 진하기로 켜짐 여부를 한눈에 알 수 있습니다.

🔁 재부팅 후 자동 실행

매번 앱과 엔진을 직접 켜지 않도록 로그인 항목과 엔진 자동 시작을 따로 설정합니다.

  1. 메뉴바의 WinMac Key 아이콘을 클릭한 뒤 설정...을 엽니다.
  2. General → Startup 카드에서 로그인 시 자동 실행을 켭니다.
  3. 재부팅 후 바로 Right Command 전환을 쓰려면 앱 실행 후 엔진 자동 시작도 함께 켭니다.
  4. 상태가 승인 필요로 표시되면 로그인 항목 설정 열기를 눌러 macOS 시스템 설정에서 WinMac Key를 허용합니다.
⚠️ 손쉬운 사용 권한이 없으면 앱은 자동 실행되어도 엔진 시작은 보류됩니다.

🖥️ VDI 환경 설정

VMware Horizon 등 가상 데스크톱에서도 한/영 전환을 사용하는 방법입니다.

🔄 동작 원리

[로컬 Mac] Right Cmd → hidutil HID remap → F16 → suppress → Control+Space 합성 → 입력소스 전환 [Mac → Mac 원격 / 화면 공유] (v1.3.5+) Right Cmd → 로컬 맥북 입력소스 토글 → 변환된 문자를 Screen Sharing이 원격 화면에 forward (로컬 맥북에만 설치하면 됨) [VDI 앱 포커스] (자동 전환) Right Cmd → hidutil HID remap → F16 → 패스스루 → Horizon: F16 → Right Alt

hidutil로 Right Cmd를 F16(modifier가 아닌 일반 키)로 변환하여 modifier flag 오염을 원천 차단합니다. VDI 앱이 포커스되면 F16이 Horizon에 그대로 전달됩니다. Mac→Mac 원격은 아래 별도 카드를 참고하세요.

🖥️ Mac → Mac 원격접속 (Screen Sharing)

맥북에서 맥미니·맥스튜디오 등에 Apple 화면 공유로 접속할 때의 한/영 전환입니다.

  1. 로컬 맥북에만 WinMac Key 설치 — 원격 Mac에는 설치 불필요
  2. 화면 공유로 원격 Mac에 연결한 뒤 원격 창에 포커스
  3. 맥북의 Right Command를 누르면 맥북 메뉴바의 입력소스가 토글됩니다 (EN ↔ 한)
  4. 이후 타이핑하면 맥북에서 변환된 문자가 원격 화면에 그대로 입력됩니다
ℹ️ Apple 화면 공유는 키 스캔코드가 아니라 변환된 문자(Unicode)를 원격에 전달합니다. 그래서 한/영 처리는 로컬 맥북에서 끝나면 충분하고, 원격 Mac의 입력소스 상태는 결과에 영향을 주지 않습니다. (VDI와 동작 모델이 다릅니다 — VDI는 F16 패스스루, Mac 원격은 로컬 토글.)
⚠️ Jump Desktop · AnyDesk · RealVNC · TeamViewer 등 타사 도구는 키 forwarding 방식이 달라 동작이 보장되지 않습니다. 실측을 권장합니다.

⚙️ Omnissa Horizon 클라이언트 설정

  1. Omnissa Horizon Client를 실행합니다.
  2. 상단 메뉴 → 설정(Preferences) 또는 ⌘+,
  3. 키보드 및 마우스 (Keyboard & Mouse) 탭으로 이동합니다.
  4. 키 매핑 (Key Mapping) 탭을 선택합니다.
  5. [+] 버튼을 눌러 새 매핑을 추가합니다.
  6. Mac 단축키(From): F16
  7. Windows 키(To): Right Alt
  8. 체크박스를 켜서 활성화 상태로 만듭니다.

🔄 기존 도구에서 전환하기

Karabiner-Elements, Hammerspoon을 사용 중이라면 아래 단계를 따라주세요.

1

Karabiner-Elements 비활성화

Karabiner는 WinMac Key와 동일한 레벨(CGEventTap)에서 키 입력을 가로채므로 충돌합니다.

  1. Karabiner-Elements 앱을 엽니다.
  2. "Profiles" 탭에서 빈 프로필(예: "Empty")을 만듭니다.
  3. 새 프로필을 "Select" 합니다.
  4. 또는 Karabiner-Elements 앱 자체를 종료합니다.
ℹ️ 완전히 제거하지 않아도 됩니다. 빈 프로필을 선택하면 모든 매핑이 비활성화되며, WinMac Key를 끄면 언제든 기존 프로필로 돌아갈 수 있습니다.
2

Hammerspoon 비활성화

Hammerspoon의 한영전환 핫키는 WinMac Key와 충돌할 수 있으므로 비활성화하는 것을 권장합니다.

  1. 메뉴바에서 Hammerspoon 아이콘(🔨)을 클릭합니다.
  2. "Quit Hammerspoon"을 선택합니다.
  3. 또는 ~/.hammerspoon/init.lua 파일 전체를 주석 처리합니다.

📋 외장 키보드 프로필

외장 키보드나 특수 배치를 사용한다면 프로필을 만들어 키보드별로 자동 전환할 수 있습니다.

1️⃣ 프로필 만들기 (3화면 표 위자드 · v1.6.0+)

  1. 설정 → General Settings → "새 프로필 만들기" 클릭
  2. 시작 화면 · 의도 선택: 프로필 이름 입력 후
    • 한/영 전환만 — 1클릭 즉시 완료. 키 배치 안 바꿈(식별 프로필). Right Command 로 한/영 전환만 합니다.
    • 키 배치도 바꾸기 — 매핑 표로 이동
  3. 키보드 형태: 실제 키캡 순서를 선택합니다. Keys-To-Go 2처럼 Ctrl · Fn · Opt · Cmd면 포터블 Mac 4키를 선택합니다.
  4. 매핑 표: 포터블 4키의 Mac 추천값은 Cmd · Fn · Opt · Ctrl, VDI 자동값은 Ctrl · Win · Win · Alt입니다. 초기화하면 선택한 형태의 추천값으로 돌아갑니다.
  5. 확인·저장: 매핑 요약 확인 후 "저장하고 적용" 클릭. 활성 프로필로 즉시 적용됩니다.
ℹ️ 키보드를 누를 필요 없음 — macOS 가 모든 키보드를 같은 키코드로 보고하므로 표만으로 충분합니다 (Mac/Windows 듀얼모드 키보드 포함). 저장된 프로필은 현재 앱 컨텍스트(Mac 로컬 / VDI)에 따라 자동 전환됩니다.
ℹ️ 기존 프로필의 보조 Fn 키(auxiliaryFnKey) 설정은 편집 시 자동 보존되며 새 위자드 UI 에는 노출되지 않습니다. 변경하려면 프로필을 삭제하고 재생성하세요.

2️⃣ 키보드에 프로필 바인딩 (Press-to-bind)

v1.3.6부터 "직전에 어떤 키보드를 썼는지" 기억할 필요 없이, 바인딩할 키보드의 키를 직접 눌러 지정합니다.

  1. Profiles 탭에서 프로필의 "Bind keyboard…" 버튼 클릭 → 모달이 열립니다
  2. 바인딩할 키보드에서 아무 키나 한 번 누릅니다 (10초 대기)
  3. 감지된 디바이스 정보(이름 · VID:PID · 내장/외장)를 확인하고 확인을 누릅니다
  4. 키 입력이 어려우면 모달 하단의 연결된 키보드 목록에서 직접 선택할 수도 있습니다
ℹ️ 한 키보드에는 하나의 프로필만 바인딩됩니다. 다른 프로필에 이미 바인딩된 키보드를 다시 바인딩하면 자동으로 이전됩니다.

3️⃣ 처음 보는 키보드 안내 (First-seen 프롬프트)

v1.3.8부터, 바인딩되지 않은 외장 키보드로 처음 입력하면 안내 창이 자동으로 떠 어떻게 처리할지 묻습니다.

🔄 자동 전환 정책 (v1.3.8 보수화)

의도하지 않은 매핑 변화를 줄이기 위해, 자동 전환은 아래 경우에만 일어납니다.

상황동작
외장 → 내장 키보드로 전환자동 전환 (안전한 기본값으로 복귀)
외장 → 다른 외장 키보드로 교체자동 전환 안 함 — 마지막 프로필 유지 (직접 선택해야 변경)
바인딩된 키보드 첫 연결해당 프로필 적용
"무시"로 등록한 키보드자동 전환·안내 모두 차단
ℹ️ 우선순위는 디바이스 프로필 > 앱 프로필 > 기본 프로필 순입니다. 외장 키보드끼리 바꿀 때 매핑이 멋대로 바뀌지 않으니, 원하는 프로필은 메뉴에서 직접 선택하면 됩니다.

❓ FAQ & 문제해결

자주 묻는 질문과 해결 방법입니다.

앱을 실행했는데 키 매핑이 동작하지 않아요

1. 메뉴바에서 엔진이 "WM"인지 확인하세요.
2. 손쉬운 사용 권한이 허용되어 있는지 확인하세요.
   (시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용)
3. Karabiner-Elements가 실행 중이면 반드시 비활성화하세요.
4. 앱을 종료 후 다시 실행해보세요.

한/영 전환이 안 돼요

Right Command 키를 짧게 "탭"해야 합니다. 길게 누르거나 다른 키와 함께 누르면 단축키 조합으로 인식됩니다.

또한 macOS의 "이전 입력 소스 선택"이 반드시 Control + Space로 켜져 있어야 합니다:
시스템 설정 → 키보드 → 키보드 단축키... → 입력 소스

한글 입력 소스가 등록되어 있는지도 확인하세요:
시스템 설정 → 키보드 → 입력 소스 → 편집... → + → "한국어 - 2벌식" 추가

입력 소스 전환창이 뜨거나 두세 번 눌러야 바뀌어요

다른 앱이 같은 전환 키를 함께 처리할 때 발생합니다.

1. Karabiner에서 right_command, Control+Space 관련 규칙을 끄세요.
2. Hammerspoon/BetterTouchTool에 한영 전환 핫키가 있으면 해제하세요.
3. 특히 Karabiner의 Right Command 규칙이 켜져 있으면 중복 실행되어 전환창이 뜰 수 있습니다.

VMware에서 한/영 전환이 안 되나요?

VDI 환경에서는 F16 → Right Alt 매핑이 필요합니다.
v1.3.0부터 F16 HID remap 아키텍처로 modifier flag 오염이 원천 차단되어 Win+P, Shift+영문 등의 오발이 해결되었습니다.
위의 VDI 환경 설정 섹션을 참조하세요.

로컬 Mac에서 첫 글자가 영어로 들어가요. 예: xㅓ미널

입력소스 전환이 실제로 확인되기 전에 첫 글자가 먼저 풀리면 생길 수 있습니다.

최신 버전은 입력소스 변경 검증 + 최소 홀드 뒤에 버퍼를 풀도록 보강했습니다.
그래도 재현되면 Control+Space 설정, Caps Lock 한영전환, Karabiner/Hammerspoon 중복 핫키를 먼저 확인하세요.

Karabiner-Elements와 동시에 쓸 수 있나요?

권장하지 않습니다. 두 프로그램 모두 CGEventTap을 사용하여 같은 레벨에서 키 입력을 가로채므로 충돌합니다.

Karabiner에서 fn/Cmd/Ctrl/Right Cmd 관련 매핑을 제거하면 공존할 수 있지만, WinMac Key만 사용하는 것을 권장합니다.

손쉬운 사용 권한을 허용했는데 동작하지 않아요

macOS에서는 권한 변경 후 앱을 재시작해야 적용됩니다.
WinMac Key를 완전히 종료(메뉴바 → "WinMac Key 종료") 후 다시 실행하세요.

그래도 안 되면 손쉬운 사용 목록에서 WinMac Key를 제거한 뒤 다시 추가해보세요.

외장 키보드에서도 동작하나요?

네! WinMac Key는 모든 키보드 입력을 시스템 레벨에서 인터셉트하므로 내장, USB, Bluetooth 키보드 모두에서 동작합니다.

위의 외장 키보드 프로필 섹션에서 커스텀 프로필을 설정할 수 있습니다.

WinMac Key 1.8.1과 1.8.2가 같이 실행돼요

Applications 설치본과 예전에 실행한 개발 빌드가 로그인 항목에 함께 남은 경우입니다. v1.8.3부터 비표준 위치의 복사본은 실행을 양보합니다. 기존 개발 빌드를 종료하고 시스템 설정 → 일반 → 로그인 항목에서 Applications가 아닌 WinMacKey 항목을 제거하세요.

🛟 비상 초기화

설정이 꼬였거나 앱이 비정상 종료된 경우 사용하세요.

⌨️ 메뉴바가 응답하지 않을 때 (글로벌 단축키)

메뉴바 아이콘을 눌러도 팝오버가 안 뜨면, v1.3.8부터 추가된 우회 단축키로 Doctor(진단·복구) 창을 바로 열 수 있습니다.

⌘⇧⌥ DDoctor 열기

Command + Shift + Option + D — Doctor에서 엔진 재시작·정지·긴급 복구를 실행할 수 있습니다.

🔧 방법 1: 앱 내 초기화

메뉴바 아이콘 → "설정 초기화..." 클릭

💻 방법 2: 터미널 수동 초기화

# 모든 HID 매핑 즉시 해제 hidutil property --set '{"UserKeyMapping":[]}' # 내장 키보드 매핑도 해제 hidutil property --matching '{"Product":"Apple Internal Keyboard / Trackpad"}' --set '{"UserKeyMapping":[]}'

🔄 방법 3: 재부팅

모든 hidutil 매핑은 재부팅하면 자동 해제됩니다. 가장 확실한 방법입니다.

🔍 현재 매핑 상태 확인

# 글로벌 매핑 확인 hidutil property --get UserKeyMapping # 내장 키보드 매핑 확인 hidutil property --matching '{"Product":"Apple Internal Keyboard / Trackpad"}' --get UserKeyMapping
